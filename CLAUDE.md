# Session startup

Before doing any work, read `TODO.md`'s "Next" section — it is the live, granular task
tracker (in-progress attempts, job IDs, exact next steps). It's gitignored/untracked by
deliberate choice, not an oversight; edit it freely without re-justifying that.

Do **not** treat `README.md`'s `## Status` section as current task state — it's a static,
human-facing summary updated occasionally, not kept minute-to-minute current. `TODO.md` is
the source of truth for "what's happening right now."
